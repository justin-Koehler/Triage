# Roadmap

Planung liegt im GitHub Project **[CRITR — Nächste Schritte](https://github.com/users/justin-Koehler/projects/9)**. Issues sind die Arbeitspakete.

## Stand (MVP)

- Dialog-Intake, KI-Steckbrief, Review, lokales Anlegen
- Workspace-Hub, Status-Update, Aufwandstabelle
- Jira-Outbox, Fake-Port für Tests
- Docker Compose, K8s-Vorlagen, CI (Lint, Tests, Audit, Image)

## Als Nächstes

1. **Auth** — SSO/OIDC statt Dev-Login; Settings nur für Admins
2. **Go-Live** — Secrets, TLS, Domain, Host-Härtung, Image in die Registry
3. **Produkt** — Risiken-Texte schärfen; CI auf den Default-Branch `root` legen

## Bewusst später / nicht MVP

- Forecasting, Ist-Zeiten, Dashboards
- Freigabematrix als Workflow-Engine
- Öffentliche Erreichbarkeit ohne SSO
