# Themen

Pro Thema eine Markdown-Datei. Match über Stichwörter, für ähnliche Fälle
und `similar_solution`. Keine Extra-Fragen — der Steckbrief kommt aus dem PDF.

Themen: `prozess`, `software`, `organisation`, `kommunikation`.

## Frontmatter

| Feld | Pflicht | Bedeutung |
|---|---|---|
| `name` | ja | Kurzname |
| `match` | ja | Stichwörter |
| `kind` | nein | immer `change_request` |
